# v0.2.2 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open a protected-branch release-stamp pull request for CovenCave v0.2.2 from approved cut `817bb717ff4ffb3e03944426802f77ff86b88d75`, without merging, tagging, or dispatching a release.

**Architecture:** Extend the existing release-stamp helper so its declared version surfaces match the five shipped desktop/iOS manifests, then enforce that contract in focused tests. Apply the v0.2.2 stamp and a curated changelog on the existing isolated release branch, validate release-specific contracts, and open a PR whose body records the immutable cut and the unpublished CLI blocker.

**Tech Stack:** Node.js 24, JavaScript/TypeScript assertion tests, Tauri JSON/TOML manifests, XcodeGen YAML, Git, GitHub REST API, Beads.
