# Bounded automation history metadata export

Parent #5217 criterion 8; implementation child #6213. The user authorized continuation through ready Cave work. This is a diagnostic export of the already displayed history page. Coven remains the authority, and authenticated receipts, approvals and the full privacy profile remain upstream acceptance requirements.

Export at most 100 validated entries and 65,536 UTF-8 bytes to the fixed filename `coven-automation-history-metadata.json`. The schema is `cave.automation-history-metadata.v1`. The root contains only schemaVersion, source (`cave-history-projection`), scope (`single-page`), completeHistory (`false`), freshness (`read` or `stale`), normalized UTC readAt, withheld and entries. Each entry contains only id, sequence, normalized UTC recordedAt and type from the fourteen known history labels, or `unrecognized`.

Use `parseAutomationHistory` as the validation boundary and rebuild a closed output. Reject invalid or unavailable input with a fixed generic error. Omit automation names/paths, details, summaries, reasons, prompts, logs, artifacts, opaque checkpoints, host identity and unknown properties. Unknown label text must never enter the packet. Normalize accepted timestamps before serialization. The packet does not establish execution or approval authority and does not authenticate receipts.

Add an explicit Export metadata button beside the existing history controls. It downloads only the current page without another read, daemon mutation, pagination or persistence. Disable it while loading or before an available page exists. A retained page after a failed read exports as stale with its original readAt. A selection change or unmount must not permit a late page from a different automation. Prepare a JSON Blob and fixed-name temporary anchor using existing browser patterns; remove the anchor and revoke its object URL on every path. Preserve focus and announce preparation, rather than claiming a file was saved. Failures use generic actionable copy. Reuse Button and existing tokens; verify keyboard and dark/light presentation.
