# Legacy Beads references

Beads is retired from this repository's development workflow by issue #5399.
Use [GitHub work tracking](../../../docs/workflows/github-work-tracking.md).
Do not run `bd` or restore Beads context hooks.

Preserve old IDs, records, owners, statuses, dependencies, and linked issues
as historical notes. The committed `.beads/issues.jsonl` is a passive export,
not the current queue. A legacy status is not proof of live execution.

When a specific old outcome is intentionally resumed, reuse its linked GitHub
issue or create one scoped authorized issue with the legacy ID. Do not
bulk-import the archive, close old records, or overwrite their owners.
