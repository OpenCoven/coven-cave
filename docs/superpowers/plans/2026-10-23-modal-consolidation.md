> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox syntax for tracking. The user has authorized local implementation; do not request routine per-task approval.

**Goal:** Remove every feature-owned web modal shell, use one prop-driven Modal, review every modal layout, and deliver a concrete checklist for other repeated component families.

**Architecture:** Extend the existing Modal and focus/portal system. Feature adapters retain data and workflow state while Modal owns layout, dismissal, focus and presentation. Use a React-owned bridge for imperative Markdown viewers and include the optional Research package in completion accounting.

**Tech Stack:** React 19, TypeScript, Next.js 16.3.8, existing CSS tokens, Vitest/react-test-renderer and Playwright; native Tauri acceptance where required.

## Review focus

- Busy mutation plus Escape/backdrop/header close: all dismissal is gated without releasing focus.
- Nested popover, avatar, iframe, or modal: visual and keyboard ownership agree; one Escape closes one eligible layer.
- Hidden retained chat drawer and inline/fullscreen reader: state survives and hidden content is not focusable or counted as native-webview cover.
- Long title/footer plus narrow/touch viewport: heading wraps, actions remain reachable, scroll stays in the body and safe areas are respected.
- Opener unmounted or navigation replaces the dialog: focus lands in the next logical destination rather than hidden or detached content.
