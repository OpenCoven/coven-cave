## Correct collection after simulator shutdown

Hosted run 43834925406 established a collector defect: the exact selected simulator is also the result bundle's device, but it is shut down after XCTest. `simctl spawn` therefore failed with exit 149 in 1.584 seconds. Preserve this failure and the Debug delayed-history first failure; the instrumented strict 21/21 result does not clear the original uninstrumented failure.

Nova's correction keeps the existing 15/5/5/5-second owner and one-minute step. A small Python helper discovers only the exact selected device through `simctl list devices <UUID> --json`, requires one exact match and an admitted state, then uses the existing live query if Booted or the host log reader against that device's `data/var/db/diagnostics` store if Shutdown. For the offline path, require an absolute existing data directory whose UUID parent matches the selected device, and an existing resolved store confined within that directory. Missing, ambiguous, redirected, malformed or transitional metadata fails closed before log reading. Preserve the fixed CovenCave/marker predicate, 70-minute lookback, true query exit status and independent receipts. Never boot a simulator as a collection workaround or query the global host store.
